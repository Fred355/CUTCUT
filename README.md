# CUTCUT

本地桌面多轨剪辑软件，优先面向 macOS。第一版实现 **导入 → 时间线编辑 → 保存/重开工程 → 真实 MP4 导出**，无需账号、API 密钥或云后端。

## 运行

使用 Node.js 22.12+（本环境验证版本：24.22.1）与 npm。在仓库目录运行：

```bash
npm ci
npm run dev
```

也可以运行构建后的应用：

```bash
npm run build
npm start
```

安装依赖时会下载 Electron、FFmpeg/ffprobe 及本平台 Canvas 二进制；安装完毕后，剪辑和导出无需联网。固定依赖记录在 `package-lock.json`，字体包含在仓库内。`npm run build` 会验证媒体工具所需滤镜，并记录实际工具版本、SHA-256 及许可证到 `resources/toolchain/`，打包时一并携带。

浏览器直接打开 Vite 只能查看首页；本地文件、工程保存和视频导出必须在 Electron 中使用，不提供伪造的浏览器演示功能。

## 开始剪辑

1. **创建工程**：输入名称，选择横屏 1920×1080 或竖屏 1080×1920，然后选择项目存放位置。帧率固定为 30fps。
2. **导入素材**：点击导入按钮，或从 Finder 将一个或多个本地文件拖入素材库。支持 MP4/MOV、JPEG/PNG、MP3/WAV/M4A。复制原件进入项目文件夹，生成缩略图和预览代理。损坏文件会单独报告；其他成功导入的文件可继续使用。
3. **添加到时间线**：点击素材旁的 `＋`，或拖到对应类型轨道。可添加视频、图片、文字和音频轨道；上层轨道覆盖下层。同轨片段不允许重叠。
4. **剪辑**：拖动片段移动位置；拖动左右边缘裁剪；在播放头位置拆分。属性栏可以精确输入起点、源入点和持续帧数。`30 帧 = 1 秒`，时间码显示 `分:秒:帧`。
5. **画面和声音**：在预览中直接选择并拖动文字、视频或图片，拖动选框四角等比缩放；也可在属性栏精确设置位置和大小。素材旁的“添加画中画”按钮会创建上层轨道并缩小画面。新文字默认覆盖选中的视频片段；已有短文字可在属性栏点击“覆盖视频全程”。可修改文字字号和颜色，调整音量或静音。图像坐标以画布左上角为原点，缩放 1 表示等比适应画布。图片默认 3 秒。
6. **保存**：手动保存 `.cutcut`；未保存修改会写入自动恢复草稿。重新打开时可选择恢复草稿。退出前有未保存提醒。
7. **导出成片**：选择 MP4 路径，实际使用原素材渲染 H.264/AAC、30fps、项目分辨率、BT.709 SDR 视频。空白画面为黑色，空白音轨为静音。导出可取消，临时文件不会替换已有成片，完整解码验证通过后才提交结果。

快捷键（焦点不在输入框时）：空格播放/暂停，左右键逐帧，B 拆分，Delete/Backspace 删除，⌘S 保存，⌘Z 撤销，⌘⇧Z 重做。非 macOS 使用 Ctrl。

## 工程文件

```text
我的工程-xxxxxxxx/
  project.cutcut           # 版本化 JSON；可再次编辑
  assets/                  # 导入原素材的副本
  cache/                   # 代理和缩略图；可重新生成
  .cutcut-recovery.json     # 存在未保存修改时生成
```

**移动工程时移动整个项目文件夹**，不要仅复制 JSON。工程不嵌入视频。素材丢失时，在素材库选择“重新定位”，指定类型、尺寸、时长一致的原始文件。输入原件不会被编辑操作修改。项目不会自动删除可能仍被历史版本引用的素材副本。

## 验证

```bash
npm run typecheck
npm run tools:check
npm test
npm run build
npm run test:ui
```

`npm test` 使用 FFmpeg 生成固定素材，测试模型、工程保存/迁移/恢复、像素与音频、真实导出、取消、损坏文件和写入失败。桌面端到端测试只替换系统文件选择框，真正执行 Electron IPC、导入、播放、编辑、文件保存及 MP4 导出。

Linux CI 需要显示服务，可使用 `xvfb-run -a npm run test:ui`。仅在隔离的 CI 中，如果 Chromium 沙箱不可用，可设置 `CUTCUT_TEST_NO_SANDBOX=1`；应用正常运行不关闭沙箱。macOS 测试不使用 Linux 参数。

## macOS 打包

在目标架构的 Mac 上运行：

```bash
npm ci
npm run build
npm run test:ui
npm run package:mac
```

生成当前机器架构的 DMG/ZIP，输出到 `release/`。Apple Silicon 与 Intel 分别在对应机器上安装依赖和打包；脚本拒绝从 Linux 冒充 macOS 打包，避免带入错误架构的媒体工具。Electron、FFmpeg、ffprobe、Canvas 原生模块和中文字体随应用携带，用户不需要安装命令行媒体工具。

当前未配置 Apple Developer 签名或公证。macOS 安装、权限、实际音频播放、签名和公证仍需在 Mac 上验收；本仓库的 Linux 验证不等于 macOS 发布就绪。

## 当前边界

- 首版不含 AI、模板分析、云服务、转场、滤镜、变速、关键帧或自动字幕。
- 预览使用 Canvas/Web Audio 合成，导出使用 FFmpeg。时间线、坐标和文字布局共享；视频预览使用最长边 1280 的代理，导出使用原件。浏览器解码调度和实时压缩器可能与离线渲染有细微差异，不承诺专业监看级逐样本一致。
- HDR 识别依据素材传递函数元数据，使用 Hable 色调映射转 SDR；不支持 HDR 成片输出。缺失或错误 HDR 标签的素材不能可靠自动识别。
- 素材会复制且视频生成代理，需为项目和导出预留磁盘空间。导入期间等待处理结束；导出在后台子进程中执行，可继续编辑，但当前导出使用启动时的工程快照。
- 工程格式、接口和实现说明见 [架构文档](docs/ARCHITECTURE.md)；第三方来源见 [许可与来源说明](docs/THIRD_PARTY.md)。

## 更新到 0.1.1（暂停恢复与画布编辑修复）

先退出正在运行的 CUTCUT。在通过 Git 下载的仓库目录执行：

```bash
git pull --ff-only origin main
npm ci
npm run build
npm start
```

若通过 ZIP 下载，请将新版解压到新的目录后执行后三条命令。`npm start` 运行的是 `dist/` 与 `dist-electron/` 构建产物，因此只更新源码而不执行 `npm run build` 不会加载修复。原有 `.cutcut` 工程格式保持兼容，不要删除你的项目素材文件夹。

建议复测：连续播放/暂停/恢复三次；跨越拆分点播放并检查原声与字幕；在预览中拖动文字、缩放画中画；从 Finder 拖入视频和照片；保存后重新打开工程确认修改保留。已自定义时段的旧字幕不会被自动延长，必要时使用“覆盖视频全程”。
