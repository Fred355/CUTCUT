# CUTCUT · 本地 AI 工具开发版（基于 0.2.0）

> 当前源码已加入关闭工程返回首页、按功能配置 AI、设置 v3 迁移，以及 Whisper / sd.cpp / audio.cpp 本地 CLI 接入与模型管理。新增三个引擎的应用内源码编译安装，已实际跑通 Electron 内安装 Whisper CPU；真实权重推理、M1 Pro Metal 和完整安装包尚待验收。详见 [本地工具构建与验收](docs/LOCAL-TOOLS.md)。

面向 macOS 的本地桌面多轨剪辑软件，采用 **Electron + React + TypeScript + FFmpeg**。支持真实闭环：**导入素材 → 编辑时间线 → 保存与版本恢复 → 导出 MP4**。

本版新增工作台、主题与模型设置、持久化版本历史，以及变速、转场和关键帧。基础剪辑无需账号、API 密钥或云后端。当前已接通**代表帧初剪、云端语音转写、字幕和按语句切分**，使用你在应用中配置的真实服务；AI 结果质量及各平台可用性仍需使用实际账户验收。当前是可运行源码版本，尚未完成 macOS 发布验收。

## 安装、启动与更新

**2026-11-13 Debug 修复：** audio.cpp 编译出现 `std::to_chars is unavailable: introduced in macOS 13.3` 时，原因是旧脚本将最低部署版本固定为 13.0。现已仅将 audio.cpp 的 CPU/Metal 构建目标调整为 13.3，sd.cpp 与 Whisper 保持原配置。更新源码并执行 `npm run build` 后，在软件设置 → 音乐生成中重新点击“编译并安装运行程序”；模型无需重新下载。音乐 Runtime 要求 macOS 13.3 或更新版本。详细原因、缓存处理和验证边界见 [Debug 更新说明](docs/LOCAL-TOOLS.md)。

需要 Node.js 22.12+ 与 npm；Linux 验证使用 Node.js 24.22.1。在项目源码目录执行：

```bash
npm ci
npm run build
npm start
```

如果模型已安装却提示运行程序缺失：进入“软件设置 → 对应功能”，点击“检查编译工具”，准备好系统提示的工具后点击“编译并安装运行程序”。Whisper、sd.cpp、audio.cpp 均可在应用内完成，无需执行终端编译命令，已下载权重保留。详见 [应用内 Runtime 安装](docs/LOCAL-TOOLS.md)。

开发时使用 `npm run dev`。**`npm start` 启动已构建的应用，每次更新源码后必须重新执行 `npm run build`。**

通过 Git 获取的源码可这样更新（先退出应用）：

```bash
git pull --ff-only origin main
npm ci
npm run build
npm start
```

通过 ZIP 下载的源码请解压到新目录，再执行安装、构建和启动命令。不要删除或覆盖自己的工程素材文件夹。

安装依赖会下载 Electron、FFmpeg/ffprobe 和本平台 Canvas 二进制；字体随仓库提供。安装后，基础剪辑与导出无需联网。上述源码启动命令不自动编译本地 AI 引擎或下载权重，本地工具可在软件设置中按 [安装说明](docs/LOCAL-TOOLS.md) 编译安装。浏览器访问 Vite 仅用于界面预览，本地文件、工程保存和真实导出需要 Electron。

## 使用流程

1. **创建或打开工程**：在工作台创建工程，选择横屏 1920×1080 或竖屏 1080×1920，帧率固定 30fps。旧工程打开后自动登记到最近项目。
2. **导入素材**：在编辑器点击导入，或将 Finder 中的文件拖入素材库。应用复制原始素材、生成缩略图和预览代理，不修改源文件。
3. **添加与编辑**：点击素材的 `＋` 或拖入同类型轨道。上层轨道覆盖下层，同轨不允许重叠。移动、裁剪或在播放头处拆分，属性面板可精确输入帧数。
4. **添加画面与文字**：直接在预览中拖动图层和缩放选框，或使用属性面板。素材旁的画中画按钮创建上层轨道；文字可设置内容、字号、颜色和位置。
5. **保存与追溯**：手动保存建立检查点；顶部“版本历史”可恢复旧版本。当前工作副本会在恢复前保存到历史中。自动恢复草稿独立保存，退出有未保存提醒。
6. **导出**：输出项目分辨率、30fps、BT.709 SDR 的 H.264/AAC MP4。无画面处黑屏，无音频处静音。取消或失败不会替换已有成品。

关闭工程使用顶部入口或文件菜单；⌘W 有工程时关闭工程，无工程时关闭窗口。保存失败保持编辑状态；放弃修改会清除恢复草稿，保留磁盘工程及历史。Mac 红色按钮仍关闭窗口，⌘Q 退出软件。

快捷键（输入框以外）：空格播放/暂停、左右键逐帧、`B` 拆分、Delete/Backspace 删除、⌘S 保存、⌘Z 撤销、⌘⇧Z 重做；非 macOS 使用 Ctrl。

## 变速、转场和关键帧

### 恒定变速

片段属性支持 0.25、0.5、1、1.5、2、4 倍速。变速改变片段持续时间，不自动移动后续片段；若产生同轨重叠，操作会被拒绝。预览启用保音调，导出通过 FFmpeg `atempo` 处理音频。暂不支持倒放或速度曲线。

### 淡入淡出与交叉溶解

淡入、淡出长度以帧设置，`30 帧 = 1 秒`，同时作用于片段画面与声音。

“与下一片段交叉溶解”要求同轨存在紧接着的下一视频或图片片段。转场长度为 15 帧；下一视频需有对应长度的源入点余量，请先裁剪其开头。应用将下一片段放入上层独立轨道并向前扩展，淡入画面与音频，前一片段音频淡出。工程结束时间保持不变，操作可撤销。

### 关键帧

在不同播放头位置调整属性并点击“记录关键帧”，记录视频或图片的位置、缩放和透明度。UI 创建线性插值，首个关键帧之前及最后关键帧之后保持边界值；底层计算也支持保持插值。可清除关键帧。

**当前限制：**文字关键帧暂不支持；带关键帧或淡入淡出的片段需先清除效果才能拆分。裁剪不得使关键帧超出片段范围。效果使用现有 FFmpeg 引擎导出，未引入 MLT 或 libopenshot。

## 工程与版本历史

```text
我的工程-xxxxxxxx/
  project.cutcut           # 可再次编辑的 JSON 工程
  assets/                  # 导入原素材副本
  cache/                   # 可重新生成的代理和缩略图
  .cutcut-recovery.json     # 未保存修改的自动恢复草稿
  .cutcut-history/          # 持久化版本检查点及内容校验
```

移动时请移动**整个工程文件夹**。素材缺失时可重新定位到类型、尺寸和时长一致的原始文件。历史版本只保存工程数据、引用素材，不复制每个版本的视频；不要手动删除历史仍需使用的 `assets` 文件。

内容相同的检查点不会重复创建。保存前写入检查点，因此即使后续保存失败，历史中也可能保留此次候选内容；检查点不代表成片已经导出。版本历史不会回滚媒体文件字节。

本版可读取旧版工程。首次使用新效果会将工程标记为 **version 2**；CUTCUT 0.1.1 不支持打开 version 2，避免旧软件静默丢失效果。应用版本 0.2.0 与工程格式版本是两个不同概念。

## 模型设置与 AI 状态

软件设置按功能提供二级菜单。进入“AI 剪辑”直接选择本地/云端、平台、模型，再“保存并测试”；低成本执行放在“高级分工”，地址、超时及认证放在高级设置。旧多账户继续可选。凭据由主进程系统加密保存；安全存储不可用时仅存运行内存，不写入工程。

视觉测试发送内置图片，文字测试发送固定短文本。通过只表示接口响应，视觉、转写和生成质量需分别验收；云端测试可能计费。Bonsai 从 Ollama 实际列表选择，视觉先试 Qwen3-VL 4B-Instruct 4-bit，2B 为轻量备选。

编辑器“AI 剪辑”提供代表帧初剪、转写、字幕、SRT 和按语句切分。“生成素材”提供图片与音乐，预览/试听后点击“加入素材库”才复制到当前工程；加入时间线是独立可撤销操作。详见 [配置说明](docs/AI-SETUP.md)。

本地推理、测试和内置工具共用单任务队列，与导出互斥。明确配置为 Ollama 的连接可在任务后释放本次使用的模型，不删除权重或关闭服务；释放失败暂停后续重任务。Metal 失败需用户选择 CPU 重试。

**尚未完成：**真实本地模型和 Mac 安装包验收、完整场景检测、ASR 参与初剪规划、跨任务 Scene Memory、自动成本/质量路由、货币预算和限定片段的自然语言修改。当前初剪每段视频只分析首/中/尾代表帧。模型下载站被本云环境网络策略拒绝，真实权重锁定清单尚未生成，缺少清单时阻止打包。

实施顺序见 [后续任务清单](docs/NEXT-MILESTONES.md)。

## macOS 打包与验收

开发者在目标架构的 Mac 上执行：

```bash
npm ci
npm run build
npm run test:ui
npm run models:lock
npm run package:mac
```

DMG/ZIP 输出到 `release/`。Apple Silicon 与 Intel 分别在对应机器上安装依赖和打包，脚本拒绝从 Linux 打包 macOS。安装包携带固定源码清单和应用内编译安装器，排除开发者预编译引擎；用户首次使用时在应用内编译 Runtime、下载权重。Mac 需要 CMake 与 Xcode 命令行工具，设置页提供检查和图形安装入口。打包前检查安装器和完整模型清单，当前模型清单仍待可访问 Hugging Face 的环境生成。媒体工具、Canvas 原生模块和中文字体随应用携带；构建记录工具版本、SHA-256 和许可证。

当前未配置 Apple Developer 签名或公证。M1 Pro 上的新效果播放、系统密钥存储、权限、安装包仍待验收；Linux 测试不代表 macOS 发布就绪。

## 其他边界与文档

- 预览使用 Canvas/Web Audio 与代理，导出使用 FFmpeg 和原素材。实时解码及压缩器与离线渲染可能存在细微差异。
- HDR 根据传递函数元数据识别，通过 Hable 色调映射转 SDR；不支持 HDR 成片输出。
- 复制素材、代理、版本检查点和导出均占磁盘空间。后台导出使用启动时的工程快照。
- 暂不支持滤镜、磁性时间线、第三方工程兼容、模板分析或批量生产。
