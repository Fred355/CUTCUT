# CUTCUT · AI 接入开发版（基于 0.2.0）

> 当前源码为 AI 接入开发版：已加入单机本地/云端服务列表、角色绑定、设置迁移、代表帧初剪、Groq/OpenAI 转写、字幕和按语句切分。配置、能力范围及验证限制见 [AI 接入说明](docs/AI-SETUP.md)。基于 0.2.0 扩展，尚未完成 macOS 实机与正式安装包验收。

面向 macOS 的本地桌面多轨剪辑软件，采用 **Electron + React + TypeScript + FFmpeg**。支持真实闭环：**导入素材 → 编辑时间线 → 保存与版本恢复 → 导出 MP4**。

本版新增工作台、主题与模型设置、持久化版本历史，以及变速、转场和关键帧。基础剪辑无需账号、API 密钥或云后端。当前已接通**代表帧初剪、云端语音转写、字幕和按语句切分**，使用你在应用中配置的真实服务；AI 结果质量及各平台可用性仍需使用实际账户验收。当前是可运行源码版本，尚未完成 macOS 发布验收。

## 安装、启动与更新

需要 Node.js 22.12+ 与 npm；Linux 验证使用 Node.js 24.22.1。在项目源码目录执行：

```bash
npm ci
npm run build
npm start
```

开发时使用 `npm run dev`。**`npm start` 启动已构建的应用，每次更新源码后必须重新执行 `npm run build`。**

通过 Git 获取的源码可这样更新（先退出应用）：

```bash
git pull --ff-only origin main
npm ci
npm run build
npm start
```

通过 ZIP 下载的源码请解压到新目录，再执行安装、构建和启动命令。不要删除或覆盖自己的工程素材文件夹。

安装依赖会下载 Electron、FFmpeg/ffprobe 和本平台 Canvas 二进制；字体随仓库提供。安装后，基础剪辑与导出无需联网。浏览器访问 Vite 仅用于界面预览，本地文件、工程保存和真实导出需要 Electron。

## 使用流程

1. **创建或打开工程**：在工作台创建工程，选择横屏 1920×1080 或竖屏 1080×1920，帧率固定 30fps。旧工程打开后自动登记到最近项目。
2. **导入素材**：在编辑器点击导入，或将 Finder 中的文件拖入素材库。应用复制原始素材、生成缩略图和预览代理，不修改源文件。
3. **添加与编辑**：点击素材的 `＋` 或拖入同类型轨道。上层轨道覆盖下层，同轨不允许重叠。移动、裁剪或在播放头处拆分，属性面板可精确输入帧数。
4. **添加画面与文字**：直接在预览中拖动图层和缩放选框，或使用属性面板。素材旁的画中画按钮创建上层轨道；文字可设置内容、字号、颜色和位置。
5. **保存与追溯**：手动保存建立检查点；顶部“版本历史”可恢复旧版本。当前工作副本会在恢复前保存到历史中。自动恢复草稿独立保存，退出有未保存提醒。
6. **导出**：输出项目分辨率、30fps、BT.709 SDR 的 H.264/AAC MP4。无画面处黑屏，无音频处静音。取消或失败不会替换已有成品。

快捷键（输入框以外）：空格播放/暂停、左右键逐帧、`B` 拆分、Delete/Backspace 删除、⌘S 保存、⌘Z 撤销、⌘⇧Z 重做；非 macOS 使用 Ctrl。

## 变速、转场和关键帧

### 恒定变速

片段属性支持 0.25、0.5、1、1.5、2、4 倍速。变速改变片段持续时间，不自动移动后续片段；若产生同轨重叠，操作会被拒绝。预览启用保音调，导出通过 FFmpeg `atempo` 处理音频。暂不支持倒放或速度曲线。

### 淡入淡出与交叉溶解

淡入、淡出长度以帧设置，`30 帧 = 1 秒`，同时作用于片段画面与声音。

“与下一片段交叉溶解”要求同轨存在紧接着的下一视频或图片片段。转场长度为 15 帧；下一视频需有对应长度的源入点余量，请先裁剪其开头。应用将下一片段放入上层独立轨道并向前扩展，淡入画面与音频，前一片段音频淡出。工程结束时间保持不变，操作可撤销。

### 关键帧

在不同播放头位置调整属性并点击“记录关键帧”，记录视频或图片的位置、缩放和透明度。UI 创建线性插值，首个关键帧之前及最后关键帧之后保持边界值；底层计算也支持保持插值。可清除关键帧。

**当前限制：**文字关键帧暂不支持；带关键帧或淡入淡出的片段需先清除效果才能拆分。裁剪不得使关键帧超出片段范围。效果使用现有 FFmpeg 引擎导出，未引入 MLT 或 libopenshot。

## 工程与版本历史

```text
我的工程-xxxxxxxx/
  project.cutcut           # 可再次编辑的 JSON 工程
  assets/                  # 导入原素材副本
  cache/                   # 可重新生成的代理和缩略图
  .cutcut-recovery.json     # 未保存修改的自动恢复草稿
  .cutcut-history/          # 持久化版本检查点及内容校验
```

移动时请移动**整个工程文件夹**。素材缺失时可重新定位到类型、尺寸和时长一致的原始文件。历史版本只保存工程数据、引用素材，不复制每个版本的视频；不要手动删除历史仍需使用的 `assets` 文件。

内容相同的检查点不会重复创建。保存前写入检查点，因此即使后续保存失败，历史中也可能保留此次候选内容；检查点不代表成片已经导出。版本历史不会回滚媒体文件字节。

本版可读取旧版工程。首次使用新效果会将工程标记为 **version 2**；CUTCUT 0.1.1 不支持打开 version 2，避免旧软件静默丢失效果。应用版本 0.2.0 与工程格式版本是两个不同概念。

## 模型设置与 AI 状态

软件设置中先添加本机或云端服务，再为高级规划、低成本执行和视觉分析绑定服务与模型 ID。密钥由 Electron 主进程管理：系统支持安全存储时加密保存，否则仅在当前运行中使用，不写入工程。不要将密钥提交到 Git 或发送到聊天中。

“测试文本”和“测试视觉”分别发送固定文字和内置图片，不上传工程素材；两类结果独立记录，仅表示接口响应，不证明识别质量、语音或生成能力，也不保证服务免费。模型 ID、权限、免费额度和价格以厂商账户为准。当前未完成各平台的真实调用验收。

在编辑器顶部进入“AI 剪辑”，选择素材并输入要求。初剪按“视觉分析 → 低成本整理 → 高级规划”执行，展示方案后创建独立工程；转写使用 Groq/OpenAI，支持文稿、字幕、SRT 和按语句切分。任务显示阶段、步骤数和服务报告的 token，并支持取消。详见 [配置与操作说明](docs/AI-SETUP.md)。

## 验证

```bash
npm run typecheck
npm run tools:check
npm test
npm run build
npm run test:ui
```

当前开发版 Linux 验证：24 项核心／媒体测试、4 项 Electron 桌面测试通过。AI/ASR 测试使用固定服务响应替身，实际执行抽帧、音频提取、IPC、独立工程生成、字幕和 SRT 操作；不代表真实厂商调用或生成质量已验收。实际渲染测试检查变速时长、AAC 编码及关键帧位置抽帧。详细记录见 [验证说明](docs/VALIDATION.md)。

桌面测试只替换系统文件选择框，实际执行 IPC、导入、预览、编辑和 MP4 导出。Linux CI 需要显示服务，可使用 `xvfb-run -a npm run test:ui`。仅在隔离 CI 沙箱不可用时设置 `CUTCUT_TEST_NO_SANDBOX=1`，正常应用不关闭沙箱。

## macOS 打包与验收

在目标架构的 Mac 上执行：

```bash
npm ci
npm run build
npm run test:ui
npm run package:mac
```

DMG/ZIP 输出到 `release/`。Apple Silicon 与 Intel 分别在对应机器上安装依赖和打包，脚本拒绝从 Linux 打包 macOS。媒体工具、Canvas 原生模块和中文字体随应用携带；构建记录工具版本、SHA-256 和许可证。

当前未配置 Apple Developer 签名或公证。M1 Pro 上的新效果播放、系统密钥存储、权限、安装包仍待验收；Linux 测试不代表 macOS 发布就绪。

## 其他边界与文档

- 预览使用 Canvas/Web Audio 与代理，导出使用 FFmpeg 和原素材。实时解码及压缩器与离线渲染可能存在细微差异。
- HDR 根据传递函数元数据识别，通过 Hable 色调映射转 SDR；不支持 HDR 成片输出。
- 复制素材、代理、版本检查点和导出均占磁盘空间。后台导出使用启动时的工程快照。
- 暂不支持滤镜、磁性时间线、第三方工程兼容、模板分析或批量生产。
