## 已验证

- TypeScript 类型检查、Vite/Electron 构建，媒体工具必要滤镜、随附字体 SHA-256。
- 11 项 Node 测试全部通过：工程与时间线边界、路径安全、真实导入及代理、保存重开/草稿恢复、迁移与重新定位、H.264/AAC 真实导出、取消和已有文件保护、损坏文件、模拟 ENOSPC 保存失败、HDR 转 SDR、竖屏及原视频音轨。
- 导出断言包含红/蓝源入点、绿色画中画覆盖、中文可见像素、黑屏空白区间、音频 RMS 和音量，导出自身执行完整解码校验。磁盘满通过文件写入故障注入验证，不声称填满了真实磁盘。

- Linux 桌面测试使用 Xvfb :99；隔离云沙箱内仅测试启动显式使用 `CUTCUT_TEST_NO_SANDBOX=1`。生产应用保持 renderer sandbox 开启。

运行记录由 `npm test`、`npm run build`、`DISPLAY=:99 CUTCUT_TEST_NO_SANDBOX=1 npm run test:ui` 生成。桌面截图位于被忽略的 `test-results/`，每次 UI 测试会重新生成。

- 修复媒体范围响应：旧接口对 `Range: bytes=44-63` 返回 20 字节却使用 HTTP 200，且没有 Content-Range。新接口明确返回 206 和正确范围/长度。新增测试覆盖完整读取、字节定位、后缀范围、HEAD 和越界，Electron 测试也检查实际协议响应。
- 14 项 Node 测试全部通过；两组 Electron 流程各重复两次，4 次均通过。
- 新增桌面回归直接检查 Canvas 视频像素与 Web Audio 实际样本，覆盖暂停恢复、跨拆分点播放、跳转第二段和字幕仍然可见。
- 检查文字直接拖动、一次撤销/重做、画中画四角缩放、保存重开后坐标和大小恢复。通过真实磁盘 File、DataTransfer、preload/webUtils 及主进程执行拖入素材库，未模拟导入实现。
- 用户反馈平台为 Apple M1 Pro、通过 `npm start` 启动。当前云环境仍为 Linux，以上不替代该 Mac 的实机复测；更新后必须重新构建再启动。
