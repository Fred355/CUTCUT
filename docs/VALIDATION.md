## 模型已安装但音乐运行程序缺失（2026-11-13，后续修正）

- 根因：模型管理只下载权重，源码的 npm run build 不编译 audio.cpp。运行时二进制不在 Git 内，源码用户需在目标 Mac 上额外构建；此前提示容易使模型安装状态被理解为整个功能已安装。
- 设置页分别显示程序与权重状态；状态检查覆盖清单损坏、版本/架构不符及可执行文件缺失或权限异常。源码与安装包提供不同修复提示，附实际路径；生成面板在程序或模型未就绪时禁用开始按钮。
- npm run build、类型检查通过；npm test 41 项通过。新增测试确认已有权重在缺失/损坏运行时情况下仍被保留，并验证源码构建命令及安装包提示。故意指定不存在的 CMake，验证脚本在拉取源码前给出构建工具缺失错误。
- 新增 Electron 场景 tests/ui/native-readiness.spec.ts 通过，使用运行时状态 IPC 替身模拟“权重已安装、程序缺失”，验证设置提示、生成按钮禁用及没有启动任务。该测试不代表实际 Mac 音乐模型已经运行。
- 当前 Linux 环境无法替用户的 Mac 生成/安装 Metal 运行程序；Mac 操作步骤见 LOCAL-TOOLS.md 的报错排查段落。已下载权重无需重新下载。
