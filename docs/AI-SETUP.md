# AI 接入与基础调度（源码开发版）

## 单机本地与云端服务

设置页按外观、AI 剪辑、语音识别、图像生成、音乐生成、本地存储分类。底层保留服务 ID、独立凭据及角色映射，不再要求先建服务、另存密钥、再填绑定表。保留现有 13 家云端平台及自定义兼容服务。

1. “AI 剪辑”分别配置剪辑规划与画面理解；低成本执行放在“高级分工”。直接选择本地/云端、平台/已有账户、模型，点击“保存并测试”。
2. 同机聊天模型由用户先启动 LM Studio、Ollama 或 llama-server。默认地址分别为 http://127.0.0.1:1234/v1、http://127.0.0.1:11434/v1、http://127.0.0.1:8080/v1。CUTCUT 不启动/关闭这些外部服务。
3. “读取模型”先保存当前连接参数，再请求模型列表；失败会显示原因，允许手填实际模型 ID。地址、账户名称、认证和超时放在高级设置。
4. 本地默认无认证，不发送 Authorization；有需要时选择独立 Bearer。云端填写密钥。密钥仅由主进程管理，系统加密不可用时仅存内存。旧账户继续可选；修改多个功能共用的端点时创建独立连接，保留其他功能的端点和密钥。
5. 画面理解的测试发送内置蓝色图片，文字角色发送固定短文本。通过仅表示接口响应。视觉先测试 Qwen3-VL 4B-Instruct 4-bit，内存较紧可用 2B；8B 只做后续对比。Bonsai 27B 选择 Ollama 实际标签，保持低成本文字角色。
6. “高级分工”可启用任务后释放本次使用的 Ollama 模型。新建 Ollama 预设已明确类型；旧连接在高级设置选择“Ollama”后才会启用原生释放，不按端口推断。释放只操作本次模型，不删除权重、不关闭 Ollama；失败阻止后续重任务，可点击“重试释放”。
7. 语音识别可选择内置 Whisper，或展开云端配置使用 OpenAI whisper-1 / Groq whisper-large-v3。云端“保存并测试”检查认证与模型列表，不代替真实音频测试。模型管理与本地使用见 [本地工具说明](LOCAL-TOOLS.md)。
8. 工程中选择素材及要求，生成初剪前核对任务去向。纯本地无需云端上传勾选；混合路线逐阶段显示目的地和发送内容，必须授权。设置修订变化后重新确认。

本地只接受 `127.0.0.1`、`localhost` 或 `[::1]`，支持 HTTP/HTTPS；localhost 规范化为 IPv4。不同端口可配置独立服务。云端要求 HTTPS，不支持局域网服务。URL 不允许嵌入凭据、查询参数、片段或完整聊天端点，所有请求拒绝重定向。默认超时本地 300 秒、云端 120 秒，可调整为 5–1800 秒；自签名 HTTPS 证书仍需系统信任。

Cloudflare 在 Base URL 中替换 ACCOUNT_ID；百炼国际端点可改为 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。自定义地址填写基础路径，应用追加 `/chat/completions`。Deepgram、Pixabay/Pexels、Embedding 不属于已接入适配器。

服务端点、接口协议、认证或类型修改会清除对应连接的凭据，不影响其他服务。旧多账户保留在各功能的账户选择项中。模型列表与连接测试会实际发送请求，云端可能计费。

## 设置迁移与恢复

设置升级为版本 3，工程格式不变。v1/v2 迁移先保存原始 studio.json 为 studio-v1-backup-时间戳.json 或 studio-v2-backup-时间戳.json，再原子写入 v3。保留主题、工程登记、统计、服务、角色映射及全部凭据；v2 不合并不同账户。v1 的地域、自定义端点及 Cloudflare 账户仍按旧映射迁移。

v3 增加三个内置引擎的模型/后端选择与 Ollama 释放偏好。旧本地语音映射为内置 Whisper，不转成云端；缺少模型或运行时时给出错误。旧云端语音绑定保留。未明确识别为 Ollama 的旧本地连接不会自动卸载模型。

设置存储路径可在“本地存储”查看。迁移失败显示错误并停止启动，原文件不会清空；请保留原文件和备份，检查权限/磁盘后重试。需要回退旧版时，退出 CUTCUT，另存当前文件，再将原始备份复制回 `studio.json`。备份含系统加密后的凭据，也应作为私有文件保管；系统凭据保护可能绑定原来的操作系统账户。

本轮不修改 `.cutcut` 工程格式，不改变版本历史、预览和导出链路。

## 初剪流程

最多选择 8 份素材。每个视频抽首、中、尾 3 个代表帧，每张图片抽 1 帧；本地 FFmpeg 缩小图片后发送视觉模型。语音和完整视频不在初剪任务中上传，音频素材只提供类型和时长。

调度顺序：视觉模型描述素材 → 低成本模型整理摘要 → 高级模型返回结构化方案 → 本地校验并编译为可编辑时间线。不同模型之间传递有限长度的摘要、素材 ID、时间范围和用户目标，不传递整个对话历史。

先展示方案、源入点、时长、理由及分析覆盖范围。应用时选择新工程存放位置，复制用到的原素材并保存独立工程；不直接覆盖原时间线。任务开始后如果工程发生变化，应用会被拒绝，要求重新生成。原工程当前工作副本写入版本检查点。

本版是代表帧初剪，**尚非完整场景检测或逐帧视频理解**。不能保证检测到采样之间的精彩瞬间，也不利用 ASR 文稿自动规划；语音转写目前是独立任务。

## 转写、字幕和按语句切分

每次选择一个有音轨的素材，最多 60 分钟。选择内置 Whisper 时使用本地 small 模型，无需云端密钥或上传授权；本地与云端都分块并合并源时间码。本地转换为 16kHz 单声道 WAV，按 5 分钟分块提交 Groq `whisper-large-v3` 或 OpenAI `whisper-1`，合并源时间码。

完成后可以编辑和保存文稿。选择对应的时间线片段，可生成文字字幕、导出 SRT，或按识别语段起点拆分；保持原声、原顺序和停顿。时间戳是识别估计，语段不保证恰好是一整句话。字幕和切分应用为一次可撤销操作。带关键帧或淡入淡出的片段仍受既有拆分限制。

没有对应时间线片段时仍可查看和保存文稿，需先将素材加入时间线才能生成片段字幕或切分。

## 限制与调度边界

- 一次一个任务，可查看阶段、取消；不自动换厂商或切换付费模型。
- 初剪最多 10 个模型步骤，云端每步最多重试两次，本地不自动重试，每步输出限制 1024 tokens，规划步骤 4096 tokens。语音任务最多 12 个分块调用，不自动重试。
- 显示服务报告的输入/输出 tokens；按本地/云端区分，缺失统计显示“未提供”，本地也消耗计算资源；语音费用通常按时长。次数是模型步骤而非 HTTP 重试数。**尚无货币预算、免费配额探测、最便宜模型自动选择或跨厂商质量评分。**
- 分析摘要、方案、文稿保存在工程 `cache/ai-*`；手动保存的文稿位于 `cache/transcript-*.json`。不含密钥。尚无跨任务缓存复用、任务列表或重启后的任务状态恢复；清理 cache 会删除这些分析记录。
- 不支持自然语言修改指定片段的 Edit Commands、完整 Scene Memory 或后台多 Agent 自主工具调用。模型只能返回剪辑方案 JSON，不能执行 shell 或任意文件操作。
- 云端分析和转写会将选定内容发给所配置厂商。取消中止当前 HTTP 请求及后续步骤；不保证外部本地服务已经停止计算或释放模型内存，也不能撤回云端已处理的内容或费用。
- 本地推理、连接测试及内置工具共用单请求队列，与 MP4 导出互斥。任务启动时固定服务、模型、端点、密钥和设置修订；后续修改设置不改变运行中的任务，不自动回退到其他厂商。

## 本地运行程序安装

Whisper、sd.cpp、audio.cpp 的权重与 Runtime 分别检查。对应功能设置提供“检查编译工具”和“编译并安装运行程序”，从固定源码构建，不使用预编译支持包。Mac 缺少工具时可打开官方 CMake 下载页或系统编译工具安装对话框；工具准备好后无需终端命令。编译成功即生效，已有权重保留。详见 [本地工具](LOCAL-TOOLS.md)。
