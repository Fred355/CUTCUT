# AI 接入与基础调度（源码开发版）

## 单机本地与云端服务

设置升级为“服务列表 + 任务绑定”，允许多个自定义服务、多个账户及不同本地端口。保留 OpenAI、Anthropic/Claude、Gemini、DeepSeek、Groq、OpenRouter、Z.AI、SiliconFlow、Requesty、Hugging Face、Cloudflare Workers AI、Cerebras、阿里云百炼 13 家平台及自定义兼容服务。

1. 先在同一台电脑外部启动 LM Studio、Ollama 或 llama-server，加载自己选择的模型。CUTCUT 不安装模型、不启动/关闭服务、不卸载模型。
2. 工作台 → 软件设置 → AI 服务列表，点击本机预设，检查地址并保存。预设地址可编辑：

   | 服务 | Base URL |
   | --- | --- |
   | LM Studio | `http://127.0.0.1:1234/v1` |
   | Ollama | `http://127.0.0.1:11434/v1` |
   | llama-server | `http://127.0.0.1:8080/v1` |

3. 本地默认“无认证”，不会发送 Authorization。外部服务要求 Token 时选择 Bearer，再单独保存该服务密钥。云端使用厂商认证。凭据在主进程由系统加密保存；不能安全持久保存时仅保留在本次运行内存。
4. 读取模型列表，或手动输入模型 ID。`/models` 未实现不影响手动设置。分别点击“测试文本”“测试视觉”；视觉测试仅发送内置蓝色测试图片。结果只表示接口响应，不证明识别质量。更改地址、协议或测试模型后旧结果不再显示；测试记录仅在当前设置页面有效。
5. 在“任务绑定”中，为高级规划、低成本执行和视觉分析分别选服务与模型 ID，然后保存。可绑定同一个服务，也可分配不同端口。视觉角色需要真正支持图片输入的模型，不预设 Bonsai 或任何默认本地模型。
6. 创建/打开工程、导入素材 → 编辑器“AI 剪辑” → 选择素材及要求 → 生成初剪方案。先展示任务去向，再确认启动；纯本地无需云端上传勾选。混合任务逐阶段列出云端地址及发送内容，必须勾选授权。设置修订变化会要求重新确认。
7. 云端语音识别绑定独立的 OpenAI/Groq 服务，填写 `whisper-1` / `whisper-large-v3`。语言可选自动、中文、英语。本地 whisper.cpp、sd.cpp 制图及 audio.cpp 音乐显示“适配器未接入”，不能启动；不会强行转换为聊天请求。

本地只接受 `127.0.0.1`、`localhost` 或 `[::1]`，支持 HTTP/HTTPS；localhost 规范化为 IPv4。不同端口可配置独立服务。云端要求 HTTPS，不支持局域网服务。URL 不允许嵌入凭据、查询参数、片段或完整聊天端点，所有请求拒绝重定向。默认超时本地 300 秒、云端 120 秒，可调整为 5–1800 秒；自签名 HTTPS 证书仍需系统信任。

Cloudflare 在 Base URL 中替换 ACCOUNT_ID；百炼国际端点可改为 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。自定义地址填写基础路径，应用追加 `/chat/completions`。Deepgram、Pixabay/Pexels、Embedding 不属于已接入适配器。

服务端点、接口协议、认证或类型修改会清除该服务凭据，不影响其他服务。删除被引用的服务会被阻止，先解除对应任务绑定并保存，再删除。模型列表和连接测试会实际发送请求，云端测试可能计费。

## 设置迁移与恢复

首次打开旧版时先将原始 `studio.json` 保存为同目录 `studio-v1-backup-时间戳.json`，然后原子升级到版本 2。保留主题、项目登记、导出统计和旧加密凭据；相同连接合并，不同地域、自定义端点或 Cloudflare 账户保留独立服务。未绑定的旧自定义凭据保留但不发送到推测的新地址。旧“本地语音”保持未绑定，不自动改为云端。

设置存储路径可在“本地存储”查看。迁移失败显示错误并停止启动，原文件不会清空；请保留原文件和备份，检查权限/磁盘后重试。需要回退旧版时，退出 CUTCUT，另存当前文件，再将原始备份复制回 `studio.json`。备份含系统加密后的凭据，也应作为私有文件保管；系统凭据保护可能绑定原来的操作系统账户。

本轮不修改 `.cutcut` 工程格式，不改变版本历史、预览和导出链路。

## 初剪流程

最多选择 8 份素材。每个视频抽首、中、尾 3 个代表帧，每张图片抽 1 帧；本地 FFmpeg 缩小图片后发送视觉模型。语音和完整视频不在初剪任务中上传，音频素材只提供类型和时长。

调度顺序：视觉模型描述素材 → 低成本模型整理摘要 → 高级模型返回结构化方案 → 本地校验并编译为可编辑时间线。不同模型之间传递有限长度的摘要、素材 ID、时间范围和用户目标，不传递整个对话历史。

先展示方案、源入点、时长、理由及分析覆盖范围。应用时选择新工程存放位置，复制用到的原素材并保存独立工程；不直接覆盖原时间线。任务开始后如果工程发生变化，应用会被拒绝，要求重新生成。原工程当前工作副本写入版本检查点。

本版是代表帧初剪，**尚非完整场景检测或逐帧视频理解**。不能保证检测到采样之间的精彩瞬间，也不利用 ASR 文稿自动规划；语音转写目前是独立任务。

## 转写、字幕和按语句切分

每次选择一个有音轨的素材，最多 60 分钟。本地转换为 16kHz 单声道 WAV，按 5 分钟分块提交 Groq `whisper-large-v3` 或 OpenAI `whisper-1`，合并源时间码。

完成后可以编辑和保存文稿。选择对应的时间线片段，可生成文字字幕、导出 SRT，或按识别语段起点拆分；保持原声、原顺序和停顿。时间戳是识别估计，语段不保证恰好是一整句话。字幕和切分应用为一次可撤销操作。带关键帧或淡入淡出的片段仍受既有拆分限制。

没有对应时间线片段时仍可查看和保存文稿，需先将素材加入时间线才能生成片段字幕或切分。

## 限制与调度边界

- 一次一个任务，可查看阶段、取消；不自动换厂商或切换付费模型。
- 初剪最多 10 个模型步骤，云端每步最多重试两次，本地不自动重试，每步输出限制 1024 tokens，规划步骤 4096 tokens。语音任务最多 12 个分块调用，不自动重试。
- 显示服务报告的输入/输出 tokens；按本地/云端区分，缺失统计显示“未提供”，本地也消耗计算资源；语音费用通常按时长。次数是模型步骤而非 HTTP 重试数。**尚无货币预算、免费配额探测、最便宜模型自动选择或跨厂商质量评分。**
- 分析摘要、方案、文稿保存在工程 `cache/ai-*`；手动保存的文稿位于 `cache/transcript-*.json`。不含密钥。尚无跨任务缓存复用、任务列表或重启后的任务状态恢复；清理 cache 会删除这些分析记录。
- 不支持自然语言修改指定片段的 Edit Commands、完整 Scene Memory 或后台多 Agent 自主工具调用。模型只能返回剪辑方案 JSON，不能执行 shell 或任意文件操作。
- 云端分析和转写会将选定内容发给所配置厂商。取消中止当前 HTTP 请求及后续步骤；不保证外部本地服务已经停止计算或释放模型内存，也不能撤回云端已处理的内容或费用。
- 本地推理、连接测试共用单请求队列。任务启动时固定服务、模型、端点、密钥和设置修订；后续修改设置不改变运行中的任务，不自动回退到其他厂商。
